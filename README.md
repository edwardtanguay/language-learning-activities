# Language Learning Activities

Worksheets created with AI for self-study, tandem meetups, and online language classes — [use the live activities](https://language-learning-activities.vercel.app) or clone this repository to create your own.

## How to Use
1. Use an AI coding tool with your own AI account (e.g., Claude Code, Cursor, GitHub Copilot, or Google Antigravity — I use Google Antigravity with the **"Google AI Pro"** account for 21,99 euros per month).
2. Clone this repo (`git clone https://github.com/edwardtanguay/language-learning-activities.git`), open the folder in your AI tool, and run `/create-activity`:
   - **Italian:** `/create-activity B1 Italian, a story about a German business man who visits Milano for an IT conference, use a deep Italian male voice for the audio, create a map that shows every place mentioned in the story`
   - **Spanish:** `/create-activity B1 Spanish, a story about two friends hiking around the volcanoes near Quito in Ecuador, use a Latin American female voice for the audio, create a map that shows every place mentioned in the story`
   - **French:** `/create-activity B1 French, a story about an exchange student spending a rainy weekend in Lyon, use a clear French male voice for the audio, create a map that shows every place mentioned in the story`
3. Open `index.html` locally in your browser or push your repo to GitHub/Vercel to publish online for free.
