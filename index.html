📝 About This Collection

Welcome! This site provides focused language learning exercises inspired by the timeless look and feel of a 1970s classroom handout.

Every single activity is 100% self-contained in a single HTML file with reading text, vocabulary notes, interactive multiple-choice exercises with progress saving, and discussion questions. You can practice directly in your browser, print the sheet to paper, or download and email the file to a student or tandem partner without requiring an internet connection.
