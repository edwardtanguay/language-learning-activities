Guide for Activity Creators

How to clone, customize, create activities with AI, and publish
CREATOR MANUAL • HANDOUT #00
Repository: github.com/edwardtanguay/language-learning-activities Hosting: Vercel / GitHub Pages (Static) Format: 100% Self-Contained HTML
ABOUT THIS PLATFORM: This project is designed for language learners, tandem exchange partners, and online tutors (e.g., on Preply). You can create clean, distraction-free reading worksheets and quizzes in any language, share individual files directly, or publish your own collection online for free.

1 Clone the Repository

The entire site is static and requires no heavy build tools, databases, or complex configurations. Open your command line and clone the repository:

git clone https://github.com/edwardtanguay/language-learning-activities.git cd language-learning-activities

You can open this folder in any code editor (such as Google Antigravity IDE, Cursor, or VS Code).

2 Local Preview & Testing

Because all activity pages are 100% self-contained, you can test them immediately:

  • Direct Browser Open: Double-click index.html or any topics/<topic-slug>/index.html in your file manager to open it directly in Chrome, Firefox, Safari, or Edge.
  • Local Web Server: Or run a quick lightweight static server:
    npx serve . # or python -m http.server 8000

3 Using the AI Skill to Create New Activities

The repository includes a ready-to-use AI skill at .agents/skills/create-text-and-multiple-choice/SKILL.md.

When you run an AI coding assistant (like Antigravity), simply type:

/create-text-and-multiple-choice

You can also supply your prompt parameters directly in one line. For example:

/create-text-and-multiple-choice Spanish, B1 Intermediate, Latin American, "Ordering Food in a Mexican Taquería"
/create-text-and-multiple-choice German, A2 Elementary, "Ein Tag im Berliner Tiergarten"
/create-text-and-multiple-choice French, B2 Upper Intermediate, "Les Cafés Littéraires de Paris"
Note on Proficiency Levels: The skill understands both CEFR codes and descriptive levels:
  • Beginner (A1 / A2): Everyday basic vocabulary, present tenses, high-frequency phrases.
  • Intermediate (B1 / B2): Full descriptive texts, past/subjunctive tenses, cultural nuances, real-world scenarios.
  • Advanced (C1 / C2): Idiomatic expressions, formal and colloquial registers, debate prompts.
Standardized Languages & Color System: The platform maintains a consistent color-coded ink stamp system for 11 standardized languages: English (#9333ea), German (#7e4402), French (#333388), Spanish (#be185d), Italian (#194d19), Dutch (#d97706), Polish (#b8b8b8), Russian (#3f3f46), Greek (#0d9488), Icelandic (#06b6d4), and Danish (#ff1493).

The AI assistant will:

  1. Ask you for any missing information (Topic, Target Language, Level).
  2. Generate a new SEO-friendly directory under topics/<slug>/.
  3. Write a completely self-contained index.html styled like a 1970s school handout.
  4. Include reading text, vocabulary glossary, interactive multiple-choice questions with instant feedback and localStorage score saving, plus tandem conversation questions.
  5. Add the new activity to the catalog in the root index.html.

4 Sharing Individual Activities Offline

Every single activity generated inside topics/<slug>/index.html is completely self-contained. That means:

  • You can attach topics/regionsofecuador/index.html to an email or message it to your student or tandem partner on Skype, WhatsApp, or Telegram.
  • They can double-click it on Windows, Mac, Linux, Android, or iOS to open it locally without an internet connection or web server.
  • Progress is safely preserved in their browser's localStorage, with a built-in "Reset Worksheet" button to wipe and retry.

5 Publishing to Vercel Under Your Own Name

You can publish your personal collection online for free using Vercel:

Method A: Via the Vercel Web Dashboard

  1. Create a free account at vercel.com.
  2. Fork or push your repository to your personal GitHub account.
  3. Click "Add New... > Project" in Vercel.
  4. Import your language-learning-activities repo.
  5. In the Project Name field, choose whatever name you like (e.g., maria-spanish-worksheets or tutor-tandem-activities).
  6. Keep Framework Preset as Other (it's pure static HTML). Click Deploy.
  7. Your site is immediately live at https://your-chosen-name.vercel.app!

Method B: Via the Vercel CLI

Run the following command directly from your workspace:

npx vercel

Follow the command prompts to set your custom project name. To deploy updates later, simply run npx vercel --prod.
